# Music Audio Directory

Drop your couple's song here!

## File:
- `song.mp3` - Your favorite romantic song (e.g. your couple track)

### How it works:
- If `song.mp3` is placed here, the integrated music player will play it with smooth play/pause, scrub bar, waveform visualizer, and volume controls.
- If `song.mp3` is not yet placed, the website includes a built-in romantic ambient piano synthesizer using the Web Audio API that plays a warm, relaxing chord progression so the sound experience works immediately without any missing file errors!
